# Summary

An abstract base class defining the polymorphic interface for *degrees of truth*—values that quantify how strongly a fuzzy concept is satisfied by an individual in a fuzzy description logic reasoner.

## Description

The `Degree` abstraction exists because concept satisfaction in fuzzy description logics is graded rather than binary, and the value expressing that grade can materialise in several different underlying forms: a plain floating-point number, a MILP decision variable, or a full linear expression. Rather than forcing callers throughout the reasoner to distinguish these cases, the interface allows every degree to be manipulated uniformly, with type-specific behaviour delegated to concrete subclasses that know how to interpret their own internal representation. The contract covers exactly the operations the reasoning and optimisation machinery needs: folding the degree into larger expressions through addition and subtraction, scaling it by constants, building inequalities in which the degree serves as the right-hand side against a supplied expression and comparison operator, and probing special numeric states such as zero or one that enable simplifications during constraint generation. Equality and human-readable string rendering are also declared abstractly, while two small conveniences are provided concretely—inequality comparison defined as the negation of equality, and a debugging representation that simply mirrors the printable string form. A static factory method, `get_degree`, is part of the interface so that raw input values can be converted into the appropriate concrete degree type; the commented-out overload sketches reveal the intended dispatch to numeric, variable, and expression variants, though the abstract declaration itself raises `NotImplementedError` when invoked directly, reinforcing that only subclasses may perform the conversion.
