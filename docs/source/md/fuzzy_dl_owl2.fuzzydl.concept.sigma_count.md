# Summary

A structural container for sigma-count expressions in fuzzy description logic, bundling the counting variable, target individual, reference individuals, role, and concept that together define a condition on how many role fillers satisfy a given concept.

## Description

**SigmaCount** captures the fuzzy-DL construct in which an individual's evaluation depends on the number of entities related to it through a specific role that also conform to a particular concept, with the resulting count measured against a fuzzy set determined by a collection of reference individuals. Because these expressions feed into a mixed-integer linear programming layer, the object carries a solver-facing Variable alongside the logical components, allowing the reasoner to bind a concrete numeric value to the count during inference. The constructor deliberately performs no validation, acting purely as a data holder whose semantics are enforced downstream by the reasoning machinery that consumes it.

Several design choices support safe reuse of these expressions in larger reasoning tasks. Deep-copy semantics are provided through cloning: the variable, the target individual, every reference individual, and the concept are recursively duplicated, while the role string is shared since strings are immutable, yielding fully independent copies when the same expression appears in multiple contexts. Hashing is based on structural identity rather than object identity, combining the hashes of all constituent parts into a tuple so that logically equivalent expressions behave correctly as dictionary keys or set members. The human-readable rendering formats the whole expression as a functional sigma-count term listing every component, and the repr output delegates to that same string so logs and interactive sessions display a consistent form. Simple accessors expose each stored component, though the list of reference individuals is returned as a direct reference to the internal list, meaning in-place modifications by callers are reflected in the object's state.
