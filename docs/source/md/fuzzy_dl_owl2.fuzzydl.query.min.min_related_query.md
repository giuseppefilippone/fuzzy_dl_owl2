# Summary

Defines a query that computes the minimum degree to which two individuals are related through a given role in a fuzzy description-logic knowledge base, reducing the question to a mixed-integer linear programming optimisation.

## Description

MinRelatedQuery extends the RelatedQuery abstraction to answer questions of the form (min-related? a b R), i.e., to find the smallest membership degree of the role assertion linking two named individuals. The central design decision is to translate role membership into a linear objective: preprocessing builds a has-value concept from the role and the target individual, obtains a MILP variable representing the degree to which the subject belongs to that concept, and adds assertions binding the individual to both the concept and its negation, with the negation's degree constrained to one minus the concept's degree. That variable then forms the objective expression handed to the optimiser, so the solver's result directly yields the minimum relatedness degree. To avoid mutating the caller's knowledge base, the solve method clones it before preprocessing and optimisation, and any inconsistency discovered during solving is caught and returned as a solution flagged with an inconsistent-knowledge-base status instead of propagating an exception. Timing instrumentation records how long the query took, and dynamic blocking is enabled whenever the constructed concept involves existential restrictions, since such constructs require the more general blocking strategy for correct reasoning.
