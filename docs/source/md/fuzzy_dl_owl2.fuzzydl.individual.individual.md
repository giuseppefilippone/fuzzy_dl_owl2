# Summary

A core building block of fuzzy description-logic reasoning that models a single named individual in an ontology, together with all the concepts, role relations, and restrictions that a tableau-based reasoner attaches to it during inference.

## Description

The `Individual` class acts as a node of the completion graph that tableau algorithms construct while checking the consistency of a fuzzy knowledge base: as reasoning proceeds, the individual accumulates the concepts asserted of it, the role relations linking it to successor individuals, the abstract role restrictions governing its fillers, and the concrete (datatype) restrictions placed on its features. Supplementary bookkeeping supports the reasoner's termination checks and optimisations, including a nominal list consulted when deciding whether an individual is indirectly blocked, a set of roles subject to the "not self" rule, and a record of which fillers should be displayed for each role. All of this state is keyed by role or feature name, so the individual effectively serves as a self-contained snapshot of everything the reasoner has derived about one domain element.

Because tableau reasoning explores branches non-deterministically and must be able to backtrack, the class provides a cloning facility that reproduces the entire mutable state in a fresh instance, deliberately rebuilding dictionaries and sets and cloning nested relations and restrictions so that sibling branches never share references. A complementary pruning operation recursively severs role relations from blockable successors, keeping the completion graph consistent when a blocked or abandoned branch is discarded. Identity is deliberately name-based — equality, hashing, and the string representation all reduce to the individual's name — which upholds the unique name assumption, and consequently any attempt to relabel an individual raises an inconsistency exception rather than silently merging two identities. The class is also intended as a base for specialisation: blockability defaults to false so that only generated individuals can be blocked, and an abstract lookup for representative individuals associated with triangular fuzzy numbers allows concrete fuzzy values to be shared across the ontology instead of being duplicated.
