# Summary

A fuzzy role assertion that connects a subject individual to an object individual through a named role, subject to a lower-bound degree of truth.

## Description

The *Relation* class captures one of the fundamental building blocks of fuzzy description logics: the role (object-property) assertion. Where classical description logics can only state that a role holds between two individuals, the fuzzy extension attaches a *Degree* value expressing the minimum intensity to which the relationship is asserted to hold. Each instance stores four pieces of plain, unvalidated state — the role name, the subject individual, the object individual, and the degree — making the object a lightweight, mutable container rather than an enforcing entity. That mutability is deliberate: the participating individuals can be swapped after construction, which supports the rewriting and normalisation steps that reasoning algorithms frequently perform on assertions, and a cloning operation produces an independent copy so callers can modify one assertion without disturbing another, although the underlying individuals and degree are shared by reference rather than deep-copied. Two string renderings serve different contexts: a degree-free form, "(subject, object): role", convenient for labelling or comparing assertions, and a full form, "name >= degree", that makes the lower-bound constraint explicit, with the official representation delegating to the informal one so that logs and interactive sessions display the same human-readable summary. Type hints for the collaborating *Individual* and *Degree* types are imported only during type checking, keeping the runtime free of potential circular dependencies.
