# Summary

A quantified ordered weighted averaging (QOWA) concept that aggregates a collection of fuzzy concepts under a linguistic quantifier, deriving the aggregation weights automatically from the quantifier's membership function rather than requiring them to be supplied explicitly.

## Description

**QowaConcept** extends the ordinary ordered weighted averaging concept so that a fuzzy concrete concept — a linguistic quantifier such as *most* or *at least half* — fully determines the weighting scheme. The weights are computed by evaluating the quantifier at the evenly spaced points i/n and taking successive differences, which corresponds to the standard quantifier-guided OWA construction under the assumption that Q(0) = 0 and Q(1) = 1. Because the weights are derived rather than given, the computation validates that they are non-negative and sum to one, raising an error if the supplied quantifier is not increasing and properly normalized; this guards against mathematically invalid aggregations early, at instantiation time. The quantifier is exposed as a property, and changing it refreshes the cached display name so the textual representation always stays consistent with the current weighting semantics.

The aggregation behaves as a first-class fuzzy concept within the larger reasoning framework: it supports negation, conjunction, and disjunction by delegating to operator concepts, and it provides cloning and recursive replacement so quantified aggregations can be embedded in larger concept expressions without mutating existing structures. Its canonical string form, `(q-owa Q C1 ... Cn)`, is generated automatically from the quantifier and the aggregated concepts, and the hash is computed from the weights, the sub-concepts, the name, and the concept type, giving structurally equivalent aggregations consistent behaviour when used as dictionary keys or set members.
