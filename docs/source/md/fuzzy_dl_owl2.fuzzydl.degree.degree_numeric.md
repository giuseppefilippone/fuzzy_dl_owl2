# Summary

A concrete, float-backed implementation of a fuzzy degree that stores a single numeric satisfaction value and integrates it into the linear expressions and inequality constraints used by the fuzzy description-logic reasoner.

## Description

**DegreeNumeric** is the fully resolved counterpart to symbolic or variable-based degrees in the broader `Degree` hierarchy: instead of deferring evaluation, it holds an actual floating-point number that quantifies how strongly a concept is satisfied. The constructor deliberately coerces its argument through the standard `float` conversion, so the internal state is guaranteed to be a float regardless of whether an integer, float, or numeric string was supplied, and lightweight factory helpers support convenient construction, including the frequently needed unit degree of 1.0. Because fuzzy concept satisfiability is ultimately encoded as mixed-integer linear programming constraints, the class's central responsibility is bridging the degree abstraction and the MILP layer: it can inject its value into an `Expression` through addition or subtraction, scale itself by a constant to produce a new expression, and build an `Inequation` in which the degree acts as the right-hand side by subtracting its value from a supplied expression and applying the requested comparison operator. Type-discriminating and value-inspection predicates allow polymorphic callers to branch on whether a degree is numeric and whether it equals the special values zero or one, relying on strict floating-point equality rather than any tolerance-based comparison. Equality is defined only against other numeric degrees by comparing underlying values, hashing mirrors that comparison so instances behave correctly in sets and dictionaries, and a human-readable string representation of the form *Degree(value)* supports debugging and logging.
