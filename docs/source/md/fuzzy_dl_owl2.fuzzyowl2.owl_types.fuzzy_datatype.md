# Summary

An abstract base class that models a fuzzy datatype as a bounded interval, storing a lower and upper value that concrete subclasses in the FuzzyOWL2 framework interpret to shape their membership functions.

## Description

`FuzzyDatatype` serves as the common foundation for all fuzzy datatype representations, capturing the idea that a fuzzy number is characterised by a range of values rather than a single crisp point. Internally it holds two private floating-point attributes representing the minimum and maximum of the interval, both initialised to 0.0 so that newly created instances begin in a neutral state before being configured. Public accessor and mutator methods expose these bounds, and the setters deliberately perform no validation — they do not check that the maximum exceeds the minimum — leaving the responsibility for logical consistency with the caller or with derived classes that impose their own constraints. Because the class is declared abstract through the standard `abc` machinery, it cannot be instantiated directly and is intended to be subclassed by concrete fuzzy datatypes, such as those modelling triangular, trapezoidal, or piecewise-linear membership functions, which build their specific fuzzy logic behaviour on top of these two boundary parameters. The debug representation simply delegates to the informal string form, prioritising human-readable output over a strictly unambiguous Python expression.
