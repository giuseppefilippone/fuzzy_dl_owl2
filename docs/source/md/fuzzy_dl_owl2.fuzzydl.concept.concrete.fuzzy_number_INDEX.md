# Summary

A concrete-domain component that models triangular fuzzy numbers—uncertain quantities whose membership degree rises linearly from a lower bound to a peak and falls linearly back to an upper bound—for fuzzy description-logic reasoning, complete with fuzzy arithmetic, logical combinators, and defuzzification.

## Description

Triangular fuzzy numbers are represented as value objects that carry both a numeric shape and a concept identity, allowing them to be embedded directly in fuzzyDL/OWL 2 knowledge bases as concrete concepts rather than as mere numeric data. A class-level universe of discourse, bounded by the attributes **K1** and **K2** and defaulting to the entire real line, is shared by every number and can be narrowed globally, influencing how numbers are named and recognized throughout the reasoning pipeline. Arithmetic follows the fuzzy extension principle while keeping every operation pure: addition and multiplication combine parameters component-wise, subtraction and division pair bounds across operands so results span the widest support consistent with interval arithmetic, and all operators return fresh instances rather than mutating their operands, which keeps reasoning side-effect free. Logical negation, conjunction, and disjunction are delegated to the compound-concept machinery so that fuzzy numbers participate naturally in concept expressions through ordinary Python operator syntax, while the *Best Non-Fuzzy Performance* value defuzzifies a number into a crisp score and degenerate triangles whose parameters coincide are recognized as ordinary crisp numbers. Identity semantics are deliberately strict—equality requires the exact same type and identical parameters, and hashing incorporates the global range alongside the three defining values—yielding a lightweight, effectively immutable value object that integrates cleanly with the broader concrete-domain machinery of the fuzzy ontology reasoner.
