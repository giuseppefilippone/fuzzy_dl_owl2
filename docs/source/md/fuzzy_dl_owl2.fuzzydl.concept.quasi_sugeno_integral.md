# Summary

A Quasi-Sugeno integral aggregation operator that fuses a weighted collection of fuzzy concepts into a single fuzzy description-logic concept.

## Description

QsugenoIntegral extends SugenoIntegral to model the quasi-Sugeno integral, an aggregation operator from fuzzy set theory that combines several criteria into one value according to per-concept importance weights. Construction validates that the weights and concepts lists have matching lengths (triggering an error otherwise), assigns the dedicated QUASI_SUGENO_INTEGRAL concept type, and generates a canonical textual name of the form *(qsugeno (weights...) (concepts...))* that doubles as a serialization of the integral's configuration. Logical composition is enabled through overloaded unary minus, conjunction, and disjunction operators, all of which delegate to the shared OperatorConcept helpers so that integrals behave like any other concept inside larger fuzzy expressions. Structural manipulation is also supported: cloning produces an independent copy with duplicated weight and concept lists, while the replacement routine recursively swaps one concept for another throughout the integral and returns the negation of the rebuilt expression, leaving the original object unmodified. Hashing is derived from the tuple of weights, the hashes of the constituent concepts, the generated name, and the concept type, giving each integral a stable structural identity suitable for use in sets and dictionaries.
