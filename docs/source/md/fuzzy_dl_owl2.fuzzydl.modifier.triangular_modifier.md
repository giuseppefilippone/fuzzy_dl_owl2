# Summary

A fuzzy-logic modifier that applies a triangular membership function — rising linearly from zero at a left boundary to full membership at a peak, then falling linearly back to zero — to concepts in a fuzzy description-logic knowledge base.

## Description

TriangularModifier specialises the framework's generic Modifier abstraction with one of the most widely used fuzzy membership shapes: a triangle parameterised by a left boundary *a*, a peak *b*, and a right boundary *c*, which must satisfy the ordering *a* ≤ *b* ≤ *c*. The constructor validates this ordering and reports an error through the shared utility layer if it is violated, whereas the boundary properties can later be reassigned without re-validation — a deliberate trade-off that keeps mutation inexpensive while placing responsibility for consistency on the caller. Membership evaluation is a pure, side-effect-free computation: inputs outside the interval [*a*, *c*] receive degree 0, inputs between *a* and *b* climb linearly toward the maximum degree of 1 at the peak, and inputs between *b* and *c* descend linearly back to 0.

Rather than mutating concepts in place, applying the modifier wraps a given Concept in a TriangularlyModifiedConcept, so modified and unmodified forms can coexist in the knowledge base and be reasoned about independently. Overloaded operators for negation, conjunction, and disjunction delegate to OperatorConcept, allowing triangular modifiers to be composed into compound fuzzy expressions using natural Python syntax. Supporting behaviour rounds out the design: cloning yields independent copies for safe reuse, a canonical name of the form *triangular-modifier(a, b, c)* aids logging and display, and hashing is derived from the name together with the three boundaries so that structurally identical modifiers can be deduplicated in sets and dictionaries.
